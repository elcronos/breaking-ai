# Breaking AI

A 25-minute talk on adversarial attacks against AI systems: their origin in 2013, attacks across every modality (text, images, audio, video, LiDAR), modern GenAI and LLM attacks (data poisoning, memorization, prompt injection), decision models, and why security and safety belong in your evals.

## Present

Open `breaking_ai_v2_standalone.html` in Chrome. It is a single self-contained file and works offline.

| Key | Action |
|---|---|
| Right arrow / Space / click | next step |
| Left arrow | previous step |
| N | presenter notes and timers |
| R | replay the current slide |
| F | fullscreen |
| M | reduced motion |
| B | blank screen |

On a phone, use the on-screen arrows or swipe. Add `#11` to the URL to jump to slide 11, or `#11-2` for slide 11 after two clicks.
